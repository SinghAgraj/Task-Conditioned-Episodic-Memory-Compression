## Overview
This project is part of the Foundations of Robotics course. It focuses on developing an episodic memory compression framework for long-running egocentric robotic vision systems operating under bounded computation and persistent memory constraints.

The objective is to study task-utility-aware memory allocation, retaining observations based on novelty, interaction, state changes, temporal context, and future task utility, to balance memory consumption and long-horizon decision-making performance.
